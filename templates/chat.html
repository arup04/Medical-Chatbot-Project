MediAid RAG Pipeline Architecture

1
Ingestion & S3 Storage

Fetches textbook PDFs dynamically from AWS S3 storage buckets via Boto3.

⬇️
2
Chunking & Preprocessing

Normalizes content, maps metadata, and splits documents using RecursiveCharacterTextSplitter.

⬇️
3
Dense Vector Ingestion

Encodes chunks into 384-dim semantic embeddings via Hugging Face Models and saves to Pinecone Serverless.

⬇️
4
Retrieval & Generation

Performs cosine similarity search on query, retrieves top context documents, and generates a structured answer using Sarvam AI.
